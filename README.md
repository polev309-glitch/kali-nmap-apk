# Kali Hunter

Простое Android-приложение для сканирования сети на базе Nmap.

**Скачать APK:** [kalihunter-1.0-debug.apk](https://github.com/polev309-glitch/kali-nmap-apk/actions) — открой последнюю успешную сборку в разделе **Actions** → **Artifacts** → `kivy-apk`.

**SHA256 APK:**

sha256:828d6a8c926df93a8afe2f6882d71849c83b721e84b55a5a4424a79eba2f89c4


## Что это

Мобильный интерфейс для Nmap с кнопками быстрого доступа к типовым сценариям сканирования:

- Быстрое сканирование (топ-100 портов)
- Сканирование всех портов
- Определение версий сервисов и ОС
- Поиск уязвимостей (NSE-скрипты)
- SYN-стелс сканирование
- Ping sweep подсети

## Требования

- Android 7.0+ (API 24)
- Установленный [Termux](https://f-droid.org/packages/com.termux/) с пакетом `nmap`
- Внутри Termux выполнить: `pkg install nmap`

## Сборка

Приложение собирается автоматически через GitHub Actions при каждом коммите в ветку `main`.

Готовый APK можно скачать в разделе **Actions** → последняя сборка → **Artifacts** → `kivy-apk`.

## Технологии

- Python 3.11.9
- Kivy 2.3.0
- KivyMD 1.1.1
- python-for-android
- Buildozer

## Установка APK

1. Скачай `kalihunter-1.0-debug.apk` из артефактов сборки
2. Скинь на телефон
3. Разреши установку из неизвестных источников
4. Установи

## Использование

1. Установи Termux из F-Droid
2. В Termux выполни: `pkg install nmap`
3. Открой Kali Hunter
4. Введи IP, домен или подсеть
5. Выбери режим сканирования

## Важно

Приложение использует Nmap для сканирования сетей. **Используй только на своих сетях или с письменного разрешения владельца.** Сканирование чужих сетей без разрешения незаконно.
